制作教程：宠物、键盘与鼠标

1. 选择上方资源分类与 2D / 3D。宠物先导出当前模型；键盘或鼠标点击下方“导出创作模板”。所有文件使用 UTF-8 保存。

2. 修改唯一 ID、名称、修订号和颜色。宠物使用 .kurocat.json，适配器 canvas-cat-v1 / three-cat-v1 声明支持模式；键鼠使用 .diycat.json，通过 modes 指定 2d / 3d。

3. 版本 1 是程序化外观资源：宠物继承内置骨架、输入反应、抚摸、道具、打盹与起床气；键盘继承按键位置与下压，鼠标继承左右键、滚轮与爪子对位。版本 2 宠物包可携带自包含 GLB 与动作映射；也可直接导入 GLB。键鼠仍使用版本 1 外观包，VRM / Live2D 暂不支持。

4. 键盘可设计配色、图案、材质、键帽高度和逐键文字；鼠标可设计外壳、按键、滚轮、纹理和轮廓比例。导入后分别预览 2D / 3D，再验证 65 / 108 配列、点击和道具动作。

5. 上传资源包至 GitHub 的 model-store 文件夹，Actions 会校验并生成 catalog.json（宠物）或 resources.json（键鼠）。更新时保留 ID 并提高 revision。刷新商城后安装；删除已选资源会恢复桌面主题。

键帽与商城键鼠按 2D / 3D 独立保存；配列、灯光和默认桌面主题共用。
