# 奶蛙分层素材

本目录素材依据用户提供的 1536 × 1024 奶蛙设计图提取，用于 DIY-Cat 的 `canvas-naiwa-v1` 绘制器。参考图及角色设计的权利归原权利人；本说明不另行授予原设计的版权许可。

| 文件 | 用途 |
| --- | --- |
| body.png | 连续头身轮廓，保留原图光影和肚皮；移除静态五官，以便独立绘制表情 |
| prone.png | 参考图的正面趴姿，移除静态五官和固定手臂，用于伏到键盘上的睡姿 |
| belly-mask.png | 肚皮换色分区，不改变身体透明度 |
| hand.png | 保留参考图手掌样式供创作对照；运行时手臂、掌心与手指统一生成，不叠加此贴片 |
| foot.png | 坐姿脚掌；普通键鼠输入由双手完成，只有原尾巴按键映射使用脚 |
| reference.webp | 缩小后的原设计图，供 HTML 预览对照 |
| artwork.json | 源图尺寸、裁剪范围、归一化坐标、坐姿/趴姿轮廓采样及部件说明 |

运行时由 [naiwaArtwork.ts](../../naiwaArtwork.ts) 解码素材并按模型配色保留明暗换色，最多缓存 12 套配色。默认配色直接使用提取素材。[naiwaRenderer.ts](../../naiwaRenderer.ts) 绘制坐姿与趴姿身体、手脚、独立眼皮与嘴部；[naiwaDeform.ts](../../naiwaDeform.ts) 控制无固定肘部的连续手臂、掌心、手指及嘴边两侧的小腮包。[naiwaPose.ts](../../naiwaPose.ts) 定义动作姿态通道，供后续适配器参考。

生气时只在嘴巴两侧局部鼓腮，保留头部外轮廓和眼睛位置，搭配斜压眼皮、收紧嘴型与轻微泛红，安抚后逐渐回落。手部使用连续轮廓统一填色，掌心沿伸手方向转动，指尖接触点与中段形变分别处理，以保持键盘、鼠标和道具对位。

睡觉通过 `sleep` 通道在坐姿与参考图趴姿之间混合，同时降低并摊宽头身、前臂向内放松、下巴靠近键盘。趴姿旧眼睛区域使用邻近皮肤的渐变重建并羽化，减少环形修补痕迹。过渡复用一张小画布，并用插值轮廓保持身体不透明，避免重影和透出键盘；被输入、停止或道具动作打断时从当前姿态连续恢复。

## 可选的素材提取

素材已经提交到仓库。运行应用、GitHub 构建和使用模型包都不需要 Python。只有重新处理同一张设计图时才使用作者工具，依赖 Pillow、NumPy、OpenCV 和 PySide6：

```sh
python scripts/extract-naiwa-art.py path/to/reference.png
```

脚本仅接受原尺寸 1536 × 1024 设计图，裁剪及遮罩位置针对该图设置，不能用来自动处理其他角色。执行会重写本目录生成素材，需在版本控制中审查差异。

## 预览与导入边界

已有开发预览服务中打开 `/harness.html?breed=builtin-naiwa&idle=0`，对照参考图测试双手敲键、点鼠标、原尾巴按键、嘴边鼓腮、趴键盘睡觉、左右晃身、好奇探头、交替摆脚和五种道具。奶蛙专属合成音效已移除，键鼠音效仍独立设置。停止按钮会结束当前动作及道具交互。

当前模型包只导入配色和配置，不包含任意图片、骨架或动画。奶蛙仅支持 2D；没有 `three-naiwa-v1`、外部 GLB 或 Blender 动作导入功能。具体协议见 [模型包说明](../../../docs/model-packs.md)，后续 Blender 制作与接入见 [3D 奶蛙设计](../../../docs/naiwa-3d-design.md)。
