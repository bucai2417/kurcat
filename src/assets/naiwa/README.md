# 奶蛙分层素材

本目录素材依据用户提供的 1536 × 1024 奶蛙设计图提取，用于 DIY-Cat 的 `canvas-naiwa-v1` 绘制器。参考图及角色设计的权利归原权利人；本说明不另行授予原设计的版权许可。

| 文件 | 用途 |
| --- | --- |
| body.png | 连续头身轮廓，保留原图光影和肚皮；移除静态五官，以便独立绘制表情 |
| prone.png | 保留旧版趴姿素材供作者对照；当前睡眠不再使用 |
| belly-mask.png | 肚皮换色分区，不改变身体透明度 |
| hand.png | 保留参考图手掌样式供创作对照；运行时手臂、掌心与手指统一生成，不叠加此贴片 |
| foot.png | 坐姿脚掌；普通键鼠输入由双手完成，只有原尾巴按键映射使用脚 |
| reference.webp | 缩小后的原设计图，供 HTML 预览对照 |
| artwork.json | 源图尺寸、裁剪范围、归一化坐标、坐姿/趴姿轮廓采样及部件说明 |

运行时由 [naiwaArtwork.ts](../../naiwaArtwork.ts) 解码素材并按模型配色保留明暗换色，最多缓存 12 套配色。默认配色直接使用提取素材。[naiwaRenderer.ts](../../naiwaRenderer.ts) 绘制坐姿身体、手脚、独立眼皮、嘴部与口水；[naiwaDeform.ts](../../naiwaDeform.ts) 控制无固定肘部的连续手臂、掌心、手指及嘴边两侧的小腮包。[naiwaPose.ts](../../naiwaPose.ts) 定义动作姿态通道，供后续适配器参考。

生气时只在嘴巴两侧局部鼓腮，保留头部外轮廓和眼睛位置，搭配斜压眼皮、收紧嘴型与轻微泛红，安抚后逐渐回落。手部使用连续轮廓统一填色，掌心沿伸手方向转动，指尖接触点与中段形变分别处理，以保持键盘、鼠标和道具对位。

睡觉保持坐姿与脚底支撑，只轻轻点头、呼吸和放松双手。`sleep` 控制打盹，`drool` 在闭眼安静下来后让嘴角口水逐渐变长，醒来前收回；输入或停止会平滑打断，隐私模式与喝饮料时立即隐藏口水。旧趴姿素材仍保留用于创作对照，运行时不再混入睡姿。

## 可选的素材提取

素材已经提交到仓库。运行应用、GitHub 构建和使用模型包都不需要 Python。只有重新处理同一张设计图时才使用作者工具，依赖 Pillow、NumPy、OpenCV 和 PySide6：

```sh
python scripts/extract-naiwa-art.py path/to/reference.png
```

脚本仅接受原尺寸 1536 × 1024 设计图，裁剪及遮罩位置针对该图设置，不能用来自动处理其他角色。执行会重写本目录生成素材，需在版本控制中审查差异。

## 预览与导入边界

已有开发预览服务中打开 `/harness.html?breed=builtin-naiwa&idle=0`，对照参考图测试双手敲键、点鼠标、原尾巴按键、嘴边鼓腮、坐着打盹 · 流口水、左右晃身、好奇探头、交替摆脚和五种道具。奶蛙专属合成音效已移除，键鼠音效仍独立设置。停止按钮会结束当前动作及道具交互。

内置奶蛙继续使用这里的 2D 分层素材，版本 1 模型包用于调整配色和配置。独立的 [3D 作者模型](../../../art/naiwa/README.md) 已支持通过版本 2 模型包导入桌宠，包含 Blender 源文件、自包含 GLB、80 根骨骼与 8 段动画。推荐导入 [3D 奶蛙清单](../../../model-store/naiwa-3d.kurocat.json)，以启用 `three-naiwa-v1` 的键鼠布局校准；裸 `.glb` 使用通用适配器。3D 只开放包内实际映射的动作，不会自动继承 2D 的道具抓握和脚部按键动作。

在 `/naiwa3d.html` 可检查导出的 3D 动作与手部近景；导入、导出和商城协议见 [模型包说明](../../../docs/model-packs.md)，骨架与动作制作见 [3D 奶蛙设计](../../../docs/naiwa-3d-design.md)。趴下睡觉仍是后续动作设计，当前 2D / 3D 均保持坐着打盹。
